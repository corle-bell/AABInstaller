# AAB Installer

在 Android 手机上直接安装 `.aab` 文件，无需电脑和 adb。

把 AAB 转成当前设备需要的 APK 集（base + split），签名后通过系统安装器安装。适合内测分发、本地验证安装包。

## 功能

- **本地安装**：从手机存储选择 AAB，一键转换并安装
- **链接安装**：输入或扫码填入 AAB 下载链接，支持仅下载或下载后自动安装
- **签名配置**：导入 JKS / PKCS12 密钥库，选择签名后用于转换
- **设备匹配 APK**：按当前手机 ABI、分辨率、语言等生成 split APK，行为接近 PC 端 `bundletool install-apks`
- **转换日志**：显示签名信息、每个 APK 的文件名/大小/MD5，便于对比验证
- **缓存清理**：清理转换临时文件，不影响下载记录和签名配置

## 系统要求

- Android 8.0 及以上（API 26+）
- arm64-v8a 或 armeabi-v7a
- 允许「安装未知应用」权限
- 链接安装需要网络；扫码需要相机权限

## 安装

从 [Releases](https://github.com/YOUR_USERNAME/AABInstaller/releases) 下载 `app-debug.apk` 安装，或自行编译（见 [README.dev.md](README.dev.md)）。

首次安装若提示未知来源，请在系统设置中允许本应用安装其他应用。

## 使用方法

### 1. 本地 AAB 安装

1. 打开应用，点击 **选择 AAB 文件**
2. 从文件管理器选中 `.aab`
3. 确认顶部显示的 **当前签名** 是否正确
4. 点击 **转换并安装**
5. 在日志区查看转换进度和每个 APK 的 MD5
6. 按系统提示完成安装

### 2. 链接安装

1. 点击 **链接安装**
2. 输入 AAB 下载地址，或点 **扫码填入**
3. 选择：
   - **仅下载**：保存到下载记录
   - **下载并安装**：下载后自动转换安装
4. 在下载记录中可对已下载的 AAB 点 **安装**
5. 转换日志会显示签名、APK 列表和 MD5

### 3. 签名配置

1. 进入 **签名配置**
2. 点击 **导入密钥库**，选择 `.jks` / `.p12` / `.keystore`
3. 填写配置名称、别名、密钥库密码、别名密码
4. 导入成功后会自动选用，并显示证书 SHA-256
5. 之后所有转换都使用当前选中的签名

> 内置调试签名仅用于快速测试。安装已用正式签名装过的应用时，必须使用相同密钥，否则会提示签名冲突。

### 4. 清理缓存

菜单 → **清理转换缓存**，删除转换产生的临时文件。不会删除下载的 AAB 和签名配置。

## 转换日志说明

转换完成后，日志中会输出类似：

```
[10:30:01] 开始转换（签名: carout）
[10:30:01] 证书 SHA-256: 3C:4B:D0:EC:...
[10:30:15] APK: base-master.apk | 12.3 MB | MD5: a1b2c3...
[10:30:15] APK: split_config.arm64_v8a.apk | 8.1 MB | MD5: d4e5f6...
[10:30:16] 转换完成: 3 个设备匹配 APK
[10:30:20] 安装成功
```

可用 MD5 与 PC 端 bundletool 产物对比，确认转换结果一致。

## 常见问题

**提示签名冲突？**  
目标应用已用其他证书安装。先卸载旧版，或导入与线上一致的正式签名。

**转换成功但内容不对？**  
查看日志中的 MD5，与 PC 端同 AAB 的产物对比。确认选中的 AAB 是最新文件，且签名配置正确。

**清除应用数据后签名丢失？**  
自定义签名配置存在应用私有目录，清除数据会重置为内置调试签名，需重新导入。

**链接安装看不到日志？**  
链接安装页顶部有「转换日志」区域，转换时会实时更新。
